# Crosspaths - Design Inspiration

Mobbin references for the festival-matcher UI (Crosspaths). Mobbin needs a login, so open these in a browser.

- **Luma (iOS)** - https://mobbin.com/apps/luma-ios-bead4230-994f-47c2-9311-5049bf7bcace
  Event hosting / RSVP. Clean, minimal event pages, host-forward. For: event framing, the join / RSVP flow, a spot-and-time card.
- **Bumble (iOS)** - https://mobbin.com/apps/bumble-ios-fefcf818-326e-4549-b2ba-1f440759e5ee
  Dating / matching. Profiles, the match + connection UX, safety cues. For: the matching core and the "you matched" moment.
- **Rodeo (iOS)** - https://mobbin.com/apps/rodeo-ios-2f020859-d739-4651-a458-b06025107718
  Social / events (confirm the exact category on Mobbin). For: browse patterns, general reference.
- **Posh (iOS)** - https://mobbin.com/apps/posh-ios-b0aef81a-ee71-43c3-a4cd-c97ef31ceed9
  Events / nightlife discovery, guest lists, ticketing. Nightlife aesthetic. For: the festival / nightlife vibe, spots and meetups.
